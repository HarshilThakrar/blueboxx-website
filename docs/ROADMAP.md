# Project Roadmap

## Current Version: v1.0.0 (Production Ready)

**Released:** July 2026

### Included in v1.0.0
- ✅ Multi-role authentication (7 roles) via Laravel Sanctum
- ✅ Student e-commerce (Course → Payment → Certificate)
- ✅ Job & Internship application pipelines
- ✅ Expert mentorship booking with Razorpay
- ✅ B2B Company portal (Post Jobs, Receive Applicants, Download Resumes)
- ✅ College portal (Placement Drives, Reports)
- ✅ Admin portal (Full CRUD, Approvals, Analytics)
- ✅ Dynamic SEO engine with Admin Dashboard
- ✅ Production-hardened security (Rate Limiting, Policies, Transactions)

---

## v1.1.0 — Planned (Q3 2026)

- [ ] **AI-Powered Resume Analyzer**: Auto-score resumes on upload using an ML model.
- [ ] **Smart Job Matching**: Recommend jobs based on a student's enrolled course categories.
- [ ] **Live Chat**: Real-time messaging between Job Seekers and Company recruiters.
- [ ] **Google Analytics 4 Integration**: Inject GA4 measurement script via the Admin SEO Dashboard.
- [ ] **Dynamic Sitemap API**: Replace static `sitemap.xml` with a Laravel-generated dynamic sitemap refreshed daily.

---

## v1.2.0 — Planned (Q4 2026)

- [ ] **Mobile Application (React Native)**: Cross-platform app sharing the same Laravel API backend.
- [ ] **Microsoft Clarity & Meta Pixel**: Heatmap analytics for conversion optimization.
- [ ] **Automated Certificate Verification**: QR code on certificates linking to a public verification page.
- [ ] **Referral Program**: Students earn credits for referring peers who enroll in courses.

---

## v2.0.0 — Future Architecture (2027)

- [ ] **Microservices Migration**: Break the Laravel monolith into independent services (Auth, Payments, Notifications).
- [ ] **Docker & Kubernetes**: Containerize all services for horizontally scalable infrastructure.
- [ ] **Multi-Tenancy**: Allow other EdTech companies to run their own white-labeled BlueBoxx DA instances.
- [ ] **AI Proctoring**: Webcam-based quiz monitoring during online examinations.
